# ColdSigner v0.1 UI specification

## Design principles

1. **Calm, not theatrical.** Security is communicated through explicit state and consequences, not padlock decoration.
2. **One primary action.** Each sensitive screen has one visually dominant next step.
3. **Values before protocol.** Transaction effects appear before PSBT jargon.
4. **No invisible outputs.** Space pressure never justifies collapsing recipients or warnings.
5. **Honest certainty.** “Verified,” “user confirmed,” “warning,” and “blocked” are distinct states.

## Visual language

- Default to a near-black background to reduce glare during QR exchange; support system light mode only after camera contrast testing.
- Use semantic colors, never color alone:
  - neutral: normal information;
  - green + check: locally verified;
  - amber + warning icon: review required but signable;
  - red + stop icon: blocked or destructive;
  - blue: primary navigation/action.
- Use monospaced digits for BTC/sat values, fee rates, fingerprints, paths, and digest fragments.
- Render Bitcoin values with grouping and explicit unit. Never show an unlabelled decimal.
- Minimum touch target: 44 × 44 pt. QR playback controls: 52 pt minimum.
- Support Dynamic Type through accessibility sizes; transaction output rows expand vertically rather than truncate amounts.

## Core components

### Security status chip

Text and icon pairs: `Offline mode: user confirmed`, `Wallet locked`, `Mainnet`, `Testnet`, `Developer build`. “Air-gapped” must not be shown as a technically verified state.

### Bitcoin amount

Primary line: `0.012 345 67 BTC`; secondary line: `1,234,567 sats`. Users may swap the primary unit globally. Exact values are never rounded on the final review screen.

### Address row

Shows a human-scannable prefix/suffix by default, a reveal control for the full address, network badge, and amount. No copy button on signing screens. The full address remains visible long enough for manual comparison.

### Warning card

Contains severity, one-sentence finding, consequence, and remediation. Warnings are part of the scroll content and summarized beside the sign control.

### Animated QR player

Square high-contrast code with fixed quiet zone; frame rate presets 2/5/10 fps; brightness shortcut; progress loop indicator; payload type label; wallet fingerprint or PSBT digest fragment. No decorative overlay inside the code.

### Animated QR scanner

Large finder area, torch control, cancel, fragment count, approximate progress, and payload type. Parsing begins only after the decoder completes; camera frames are not stored.

Home must not resemble a hot wallet: no balance card, receive/send pair, market price, recent transactions, or broadcast state.

### Seed display

- Require landscape-independent layout and prevent words from being clipped.
- Number every word; show four columns only when accessibility size allows.
- Disable selection, copy, share, screenshots generated by app tooling, and keyboard learning.
- Add a persistent statement: “Anyone with these words can spend your bitcoin.”
- On screen capture detection, cover words and ask the user to stop capture. State that iOS cannot guarantee blocking a hardware or system screenshot.

## Content style

- Use verbs: “Scan transaction,” “Verify backup,” “Wipe signer.”
- Avoid “safe,” “guaranteed,” “military-grade,” and “bank-grade.”
- Explain blocked states in one sentence, followed by an action the user can take in the coordinator.
- Preserve standard terms in English where translation could reduce interoperability: PSBT, BIP39, BIP84, BC-UR, BBQr, fingerprint.

## Accessibility and privacy acceptance

- VoiceOver order matches visual loss-impact order.
- All icons have labels; warnings include text.
- Reduced Motion replaces QR animation only when transport is inactive; active animated QR must explain why motion is required.
- Privacy cover is verified in app-switcher snapshots.
- Sensitive text is marked privacy-sensitive and excluded from app-authored diagnostics.
- Camera permission denial leads to settings guidance, not a request loop.
