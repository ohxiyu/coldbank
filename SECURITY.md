# Security policy

## Project status

ColdSigner is pre-alpha and unaudited. Do not use it to protect real funds.

## Reporting a vulnerability

Do not open a public GitHub issue containing exploit details, seed material, PSBTs, or other sensitive data.

Until a private security contact is published, create a minimal public issue titled `Security contact request` without technical details. A maintainer will provide a private reporting channel. This interim process must be replaced before the first public beta.

The project does not currently offer a bug bounty or guaranteed response SLA.

## Supported versions

There are no supported production releases yet. Security fixes will target the latest development branch until v0.1 ships.
